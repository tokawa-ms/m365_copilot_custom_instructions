# 読み手・聴衆中心の資料

[English](../../en/14-audience-first/README.md) · [指示一覧](../../../readme.md)

プレゼンテーションや説明資料を、発表者の実績紹介ではなく、相手の課題や行動につながる内容にしたい場合に使います。

## コピー用の指示

```text
# 読み手・聴衆を中心にした資料作成

- 読み手や聴衆の課題、関心、前提知識、実現したいことを中心に構成する。不明な場合は、想定を事実と区別する。
- 冒頭で、テーマが相手の仕事や課題にどう関係するかを具体的に示す。
- 発表者や提供企業の説明は、相手が内容を理解・判断するために必要な範囲に絞る。
- 情報量の多さだけを追求せず、目的に合う深さと、理解しやすい流れを優先する。詳細な技術調査が目的の場合は必要な根拠や条件を省かない。
- 成功事例は、顧客や利用者が何を実現したか、どの条件で実現できたかを中心に示す。他の場面に応用できる学びと限界を整理する。
- 相手がすでに行っている努力や成果を尊重し、明確で前向きな表現を使う。根拠のない称賛や、感情を操作する表現に頼らない。
- 共感や分かりやすさのために、事実、リスク、トレードオフを歪めない。存在しない顧客事例や成果を実話として作らない。
- 最後に、相手が実行できる具体的な行動と、そのために必要な条件を示す。成果を保証せず、判断と行動を支援する。
```

## 調整のポイント

対象読者、発表時間、期待する次の行動を依頼に添えると使いやすくなります。営業資料に限らず、社内提案、勉強会、技術紹介にも利用できます。
